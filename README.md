# NOX Player — fait par math_0235

Lecteur de musique Android hors ligne façon Lark Player — sans pub, sans compte, sans Internet.

## Fonctions
- Bibliothèque auto : toute musique qui arrive sur le téléphone apparaît toute seule
- Onglets : Chansons, Playlists, Albums, Artistes, Dossiers, Favoris, Récents + recherche
- « ＋ Ajouter plus de musique » : importer des fichiers, convertir une vidéo en audio (.m4a), lien direct (.mp3…)
- Option : nouvelles vidéos du téléphone → audio automatiquement (Réglages ⚙)
- Modifier une musique : titre, artiste, album, photo de pochette
- Lecture en arrière-plan + notification + écran verrouillé + boutons des écouteurs
- Pause auto quand on débranche les écouteurs
- Aléatoire, répétition (tout / un), file d'attente, lire ensuite
- Égaliseur + basses, minuterie de sommeil, vitesse 0.5x → 2x
- Favoris, playlists, partager, « Ouvrir avec NOX Player »

## Obtenir l'APK
1. Crée un dépôt GitHub (ex. `NOX-Player`) et envoie tout le contenu de ce dossier dedans.
2. Onglet **Actions** → « Build APK NOX Player » se lance tout seul (~4 min).
3. Clique sur le build terminé → en bas, **Artifacts** → `NOX-Player-APK` → décompresse → installe `NOX-Player.apk`.

Ou ouvre le dossier dans Android Studio → Build → Build APK.
- Écran de lecture : couleurs tirées de la pochette, onde, paroles (à coller ou fichier .lrc)
- File d'attente : glisser ≡ pour réorganiser, 3 modes (répéter un titre / la liste / aléatoire)
- Tri : le dernier, le plus joué, A→Z, artiste, durée (⇅ pour inverser)
- Paramètres : temps de lecture, sauvegarde/restauration en fichier, thèmes, masqués, corbeille
